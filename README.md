# Birthday Surprise — Rithika's 20th Birthday Experience

A personalized interactive birthday surprise web experience created for Rithika.

## ✨ Features
- **Secret Code Gate:** Interactive security screen with customized entry code.
- **Heartfelt Reveal:** Personalized birthday greetings with custom framed photograph.
- **Interactive Cake Cutting:** Realistic drag-to-cut cake interaction with dynamic slicing physics.
- **Albums & Memories:** 10 curated memory slots with personalized poetic captions and scroll navigation.
- **Capture a Moment:** Keepsake photo display with romantic typography.
- **Interactive Scratch Card:** Realistic scratch-to-reveal canvas with celebratory confetti.
- **Background Music:** Seamless audio playback throughout the experience.
- **Final Birthday Video:** Integrated high-definition video tribute with full player controls.

## 🚀 Running Locally
To run this website locally:

```bash
# Using Node.js built-in server
npm start
# or
node serve.js
```

Then open your browser and navigate to `http://localhost:8085`.
